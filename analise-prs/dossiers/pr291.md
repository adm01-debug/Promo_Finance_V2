## Contexto

O Dependabot abriu #211 com bump zod 3→4, mas a Zod v4 introduz breaking changes em toda a base TypeScript que não foram resolvidos. Esta PR cria uma branch fix completa que migra todos os call-sites com as APIs corretas do Zod v4.

## Causa dos checks vermelhos (ciclo 1)

### 1. Prettier — `empresa-form-model.ts`

**Arquivo:** `src/components/empresas/empresa-form-model.ts`  
**Sintoma:** Quality Gate saiu com exit code 123: `[warn] src/components/empresas/empresa-form-model.ts — Code style issues found`

**Root cause:** A PR original (#211) removia o argumento `{ invalid_type_error }` dos campos `aliquota_rat` e `aliquota_terceiros`, mas mantinha formatação multi-linha. Sem o argumento longo, Prettier colapsa `.min(0, 'Mínimo 0%').max(6, 'Máximo 6%').optional().nullable()` para linha única (~88-93 chars, dentro do `printWidth`).

**Fix:** Colapsado para formato single-line (commit `5d724153`):
```typescript
aliquota_rat: z.number().min(0, 'Mínimo 0%').max(6, 'Máximo 6%').optional().nullable(),
aliquota_terceiros: z.number().min(0, 'Mínimo 0%').max(6, 'Máximo 8%').optional().nullable(),
```

### 2. Tab byte em regex — `SecuritySettings.tsx` linha 38

**Arquivo:** `src/components/configuracoes/SecuritySettings.tsx`  
**Sintoma:** Codex P1 — tab character `\t` dentro do quantificador `{3}` na regex de CIDR

**Root cause:** A branch tinha o byte extra de tab entre `{` e `3`: `\.){⇥3}` (base64 `ewk3`) em vez de `\.){3}` (base64 `ezN9`). O arquivo da branch tinha 13978 bytes vs 13977 no main — diferença de 1 byte confirma o tab inserido.

**Fix:** Reconstruído o arquivo a partir da versão do main (`\.){3}`) preservando a mudança já correta da branch: `.issues[0]` em vez de `.errors[0]` (Zod v4 mudança de API).
